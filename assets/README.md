# assets 目录说明

本目录存放**本人真实运行/取证产生的材料**，不接受任何占位图片或伪造文件。

| 文件 | 内容要求 | 拍摄要点 |
| --- | --- | --- |
| `demo_run.png` | 框架运行截图 | 终端中 `python main.py --gen dataset` 正在执行，能看到 `[12/43] xss_r ... REFLECTED_UNESCAPED` 这类进度行与最终汇总表 |
| `dvwa_success.png` | 靶场命中截图 | 浏览器访问 `http://127.0.0.1/dvwa/vulnerabilities/xss_r/?name=<script>alert(1)</script>`，出现弹窗，地址栏与 DVWA 界面同时可辨 |
| `cert/thm_cert.pdf` | 平台官方电子结业证书 | 原始 PDF，不要改文件名、不要截图转 PDF；平台出具的核验信息需与 README 第 8.2 节一致 |

## 说明

1. 截图请保留完整窗口（含地址栏或任务栏时间），避免只截局部，以证明是本机实测；
2. 若使用 TryHackMe 证书，建议同时保留个人主页的公开验证链接；若使用合天网安实验室证书，请保留平台提供的证书编号查询页；
3. 证书文件包含个人信息，上传公开仓库前请自行评估脱敏需求——若平台证书含身份证号等敏感字段，建议只保留可核验部分并加水印"仅用于升学材料"。

> 本目录在首次提交前为空是正常的：截图与证书必须由账号本人取得，任何代为生成的图片、PDF 都不应出现在这里。
